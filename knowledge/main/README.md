# main — 跨应用公共语境

本目录只放**多个应用共享**的术语、流程与约束，不写单个应用的实现细节。

## 写作边界

| 放这里 | 不放这里 |
|--------|----------|
| 全平台架构原则、依赖方向 | server/web 的具体路由或 DTO |
| 跨应用的 Run/工作流概念（待 OFFICIAL 时补充） | 插件包内的业务逻辑 |
| 全局命名或协作约定（经确认后） | 未验证的推断 |

## 当前权威来源（轻量阶段）

在尚未写入 OFFICIAL 跨应用 flow 前，优先阅读：

- 仓库根 [README.md](../README.md) 的架构图与**依赖方向**表
- [ROUTING.md](../ROUTING.md) 按应用定位

后续可在本目录按需新增 `flow-*.md` / `rule-*.md`（使用 [template/](../template/flow.md)），并同步更新 ROUTING。
