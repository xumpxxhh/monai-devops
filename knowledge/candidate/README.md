# candidate — 候选知识区

有来源但**尚未经 owner/研发确认**的结论放在此目录。AI 与人**不得**把 candidate 当作正式事实引用。

## 流转

```
personal 个人经验 → candidate 候选 → review → 合并到 applications/ 或 main/（OFFICIAL）
                              └→ REJECTED（保留记录，说明原因）
```

## 新增方式

1. 复制 [template/candidate.md](../template/candidate.md) 到本目录。
2. 填写来源、证据、待确认项、`suggestedTarget`。
3. review 通过后按目标路径写入正式知识，并将 candidate 的 `status` 改为 `MERGED`。

建议 SLA：**14 天内**处理待 review 条目（见 [KNOWLEDGE-RULES.md](../KNOWLEDGE-RULES.md)）。
